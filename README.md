# 📈 Tradescape - Trader Risk Dashboard

A modern **Trader Risk Dashboard** built with **React, TypeScript, Vite, Tailwind CSS, and Recharts**. The application helps traders monitor account performance, analyze trading metrics, visualize equity growth, and track trading risk in real time.

# ⚠️ Risk Levels

| Risk Usage    | Status               |
| ------------- | -------------------- |
| Less than 70% | ✅ Safe              |
| 70% – 89%     | ⚠️ Approaching Limit |

# ▶️ Getting Started

## 1. Clone Repository

```bash
git clone https://github.com/AmitKumarr2024/tradescape-risk-dashboard.git
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Run Development Server

```bash
npm run dev
```

## 4. Build Project

```bash
npm run build
```

## 5. Preview Production Build

```bash
npm run preview
```
