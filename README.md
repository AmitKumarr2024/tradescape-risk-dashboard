# 📈 Tradescape - Trader Risk Dashboard

A modern **Trader Risk Dashboard** built with **React, TypeScript, Vite, Tailwind CSS, and Recharts**. It helps traders monitor account performance, analyze trading metrics, visualize equity growth, and track trading risk.

## 🚀 Live Demo

https://tradescape-risk-dashboard-seven.vercel.app/

## 📂 GitHub Repository

https://github.com/AmitKumarr2024/tradescape-risk-dashboard

---

## ✨ Features

- Account Overview
- Trading Performance Dashboard
- Risk Status Monitoring
- Equity Curve Visualization
- Trade History
- Add, Edit & Delete Trades
- Search Trades
- Dark / Light Mode
- Interactive Charts
- Toast Notifications
- Responsive Design

---

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- React Hot Toast
- Lucide React

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/AmitKumarr2024/tradescape-risk-dashboard.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
